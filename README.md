# Energidryck

Lista över energidrycker med en adminsida för att redigera dem. Byggd med Node, Express, EJS och MongoDB.

## Köra lokalt

1. Kopiera `.env.example` till `.env` och fyll i din MongoDB-anslutningssträng.
2. Starta servern (kräver Node 20.6 eller senare):

```
node --env-file=.env server.js
```
